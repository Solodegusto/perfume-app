# Parfüm Tasarımcısı / Perfume Designer

**TR** — Kendi parfümünü kişilik ve karakter özelliklerine göre tasarlayabileceğin interaktif web uygulaması.

**EN** — An interactive web app that lets you design your own perfume based on your personality traits.

🔗 https://solodegusto.github.io/perfume-app/  
🇬🇧 English: https://solodegusto.github.io/perfume-app/?lang=en

## Kullanım / How to use

1. Linki tarayıcıda aç / Open the link in your browser.
2. Sağ üstten dili seç (TR / EN) / Pick a language at the top right.
3. Kişilik özelliklerini seç / Choose your personality traits.
4. "Parfümümü Oluştur" / "Create My Perfume" butonuna bas.
5. Önerilen notaları ve sonucu gör / See your suggested notes and result.
